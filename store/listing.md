# Chrome ウェブストア掲載情報

## 名前

Hover Translate

## 概要 (manifest の description と同じ)

ページ上の段落やリストを指して右クリックするだけで、その部分を日本語に翻訳します。DeepL API (Free / Pro) と Chrome 組込みの翻訳に対応。

## 説明

英語の記事やドキュメントを読んでいて、分からない段落だけを日本語にしたいときのための拡張機能です。ページ全体を翻訳せず、指した部分だけを置き換えるので、元のレイアウトを崩さずに読み進められます。

使い方

1. Ctrl+Shift+L (Mac は Command+Shift+L) で翻訳モードをオンにします。
2. 翻訳したい段落やリストにマウスを乗せると、青い枠で囲まれます。
3. 右クリックすると、その部分が日本語に置き換わります。
4. Esc で翻訳モードを終わります。

翻訳した部分は、ページを開き直しても復元されます。元に戻したいときは、Ctrl+Shift+K (Mac は Command+Shift+K) を押すか、ページの右クリックメニューから「表示中のページの翻訳を解消する」を選びます。

翻訳エンジン

- DeepL API: 自分の DeepL API キー (無料版・Pro 版のどちらでも可) を設定画面に入れて使います。
- ローカル翻訳: Chrome に組み込まれた翻訳機能を使います (Chrome 138 以降)。端末内で翻訳し、外部には送信しません。無料です。

この拡張機能は DeepL SE とは関係のない個人の制作物です。

## カテゴリ

仕事効率化 > ツール

## 言語

日本語

## 単一用途の説明

ウェブページ上で利用者が指定した要素を日本語に翻訳して置き換えること。

## 権限の理由

- storage: DeepL API キー、翻訳エンジンの選択、ページを開き直したときに復元する翻訳結果を、ブラウザ内に保存するため。
- activeTab: 右クリックメニューから、表示中のタブの翻訳を消してページを再読み込みするため。
- contextMenus: 「表示中のページの翻訳を解消する」メニューを追加するため。
- ホスト権限 (https://api.deepl.com/_, https://api-free.deepl.com/_): 利用者が DeepL を選んだときに、指定した部分の翻訳を DeepL API (Pro 版・無料版) に依頼するため。
- コンテンツスクリプト (<all_urls>): 利用者がどのページでも翻訳モードを使えるよう、マウスで指した要素の枠表示と置き換えを行うため。
- リモートコード: 使用していません。

## データの使用

- 収集するデータ: ウェブサイトのコンテンツ (利用者が翻訳を指示した要素の HTML。DeepL を選んだときだけ DeepL API に送信)
- 第三者への販売・転用・信用評価への利用: なし
